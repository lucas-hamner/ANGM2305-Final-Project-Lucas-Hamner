# Description
StyleFX is a image editing program that I made using Python, Tkinter, and the Pillow libraries. The goal of this project was to create a simple tool that lets users load an image, experiment with different visual filters, preview the result, and then save the edited version. The app runs in a single window and shows a live preview of whatever filter you choose to apply.

The program includes filters such as grayscale, sepia, blur, and brightness adjustments for lightening and darkening. I also added a few extra fun effects like invert, pixelate, etc. One of the challenges was getting the preview window to display images correctly. I fixed this by automatically scaling the preview while keeping the aspect ratio the same.

One of the design choices I made was to keep the GUI layout straightforward, with simple buttons and sliders on the right, and a preview window on the left.

In the future, I would like to expand the program with more interactive tools, such as zooming into the image, cropping, undo/redo, and maybe even drawing tools. More filters would also be fun to add, especially stylized ones like watercolor, sketch, or edge glow effects. Another improvement would be improving the look of the layout.
