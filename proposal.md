# Style FX – Photo Art Filter Tool #

## Git Repository Link |
https://github.com/lucas-hamner/ANGM2305-Final-Project-Lucas-Hamner.git

## Description |
Style FX will be a Python tool that allows users to import photos and apply filters such as watercolor, sketch, vintage, etc. It's relevant to digital arts and media because it uses both technology and creativity, helping artists edit their photos easily.

## Features |
# Image Loader
  - Let users select and load their own custom image file, displayed in a preview window
# Artistic Filters
  - Apply various filters (watercolor, sketch, glitch, vintage, etc.) using libraries like Pillow and OpenCV
# Adjustable Settings
  - Real time sliders that let you change brightness, contrast, saturation, and intensity of a filter, and more
# Save Artwork
  - Save the output as a new image file, png or jpeg
# Random Mode
  - “Randomize” button applies random combinations of sliders/filters
